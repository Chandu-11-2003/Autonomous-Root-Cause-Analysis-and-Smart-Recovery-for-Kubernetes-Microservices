# Autonomous Root Cause Analysis and Smart Recovery for Kubernetes Microservices

## M.Tech Final Year Project

### Overview
An autonomous cloud-native incident management and self-healing system for Kubernetes microservices that combines:
- Dynamic dependency modeling
- Causal root-cause analysis
- Multi-signal evidence fusion
- Confidence/risk-aware decision making
- Safe replica validation
- Graduated autonomous recovery
- Post-recovery verification
- Feedback and learning

### Research Question
Can dependency-aware causal root-cause analysis combined with confidence-aware, safely validated automated recovery reduce MTTR and incorrect remediation in Kubernetes microservice failures?
